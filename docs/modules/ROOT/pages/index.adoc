= Keycloak OID4VP Plugin Documentation

Welcome to the documentation hub for the Keycloak OpenID4VP plugin. Use this page to navigate to feature guides and how-tos.

== What you’ll find here

* OpenID4VP user authentication: how to enable the feature, initiate the flow, poll for status, and finish login.
* Authentication profiles: how to configure credential requirements, trust policies, and binding rules.
* Deployment configuration: complete reference for all authenticator settings.
* German wallet PID verification: configuration for dual-credential authentication with the German EUDI wallet.
